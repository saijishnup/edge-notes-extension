# Privacy Policy

Quick Notes is a lightweight browser extension that stores notes locally in your browser.

## Data Collection
This extension does NOT collect, store, or transmit any personal data.

## Data Storage
All notes are stored locally using the browser's storage API (`chrome.storage.local`).  
No data is sent to any external servers.

## Permissions
The extension only uses storage permission to save notes locally.

## Third-party Services
This extension does not use any third-party services.
